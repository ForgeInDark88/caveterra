# CAVETERRA

2D roguelite-платформер (вид сбоку) про спуск в бесконечную пещеру (Godot 4.7, GDScript). Вся графика рисуется кодом — внешние ассеты не нужны.

## Запуск
Открыть папку `caveterra/` в Godot 4.7 и нажать **F5**. Игра стартует в полноэкранном режиме (F11 — переключить).

## Игровой цикл
1. **Главное меню** — начать игру, полный экран, управление, выход.
2. **Лобби** — выберите стартовое оружие на одном из пьедесталов: **меч**, **лук** или **магия рук**. Есть манекен для тренировки. Затем спуститесь в шахту справа.
3. **Пещера** — вид сбоку. Каждая комната генерируется случайно: несколько ярусов с неровным полом и потолком, висячие платформы, уступы, шипы. Ярусы соединены ямами и люками-платформами (сквозь них можно спрыгнуть вниз на S), под люками — лесенки из платформ, чтобы забраться обратно. Вход — сверху слева, шахта на следующую глубину — на нижнем ярусе; она открывается после зачистки комнаты. Враги, их количество и расстановка случайны и растут с глубиной.
   - Каждая 5-я комната — босс **Пещерный Страж**.
   - Иногда попадается **сокровищница** с золотым сундуком.
4. **Сундуки** — выпадает случайное оружие одной из 4 редкостей (Обычное / Редкое / Эпическое / Легендарное). Чем глубже — тем выше шанс на редкое.

## Оружие
- **Мечи**: меч, двуручник, кинжал. Взмах по дуге, отбивает вражеские снаряды.
- **Луки**: короткий, длинный (пробивает), арбалет (веер стрел).
- **Магия рук** (тратит ману): тайная (самонаведение), огонь (взрыв), лёд (замедление, пробитие), молния (цепь).

В инвентаре до 4 слотов; при полном инвентаре новое оружие заменяет текущее.

## Враги
Слизень (прыгает), летучая мышь (летает), скелет-лучник, паук (прыжок-рывок), каменный голем (удар по области), культист (летает, огненные шары), босс (прыжок с ударом о землю, залпы, призыв).

## Управление
| Клавиша | Действие |
|---|---|
| A / D, ← / → | ходить влево / вправо |
| W / Пробел / ↑ | прыжок (держите — выше) |
| S / ↓ | спрыгнуть вниз сквозь платформу |
| Мышь / ЛКМ | прицел / атака |
| Shift | рывок (неуязвимость) |
| E | открыть сундук, подобрать, спуститься |
| Q, 1–4 | смена оружия |
| Esc | пауза |
| F11 | полный экран |

## Структура
- `scenes/` — `main_menu`, `lobby`, `cave` (корневые узлы, всё остальное строится из кода)
- `scripts/game.gd` — автозагрузка `Game`: состояние забега, инвентарь, управление, рекорды
- `scripts/room_generator.gd` — процедурная генерация комнат
- `scripts/world_tiles.gd` — отрисовка тайлов, коллизии стен и проходимых снизу платформ
- `scripts/weapon_db.gd` — генерация оружия и редкостей
- `scripts/player.gd`, `enemy.gd`, `projectile.gd`, `chest.gd`, `pickup.gd`, `portal.gd`, `hud.gd`
